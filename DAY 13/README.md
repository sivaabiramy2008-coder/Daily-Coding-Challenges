# Day 13 - LeetCode Solutions

## Problem 1

**Problem Name:** Left and Right Sum Differences

**Platform:** LeetCode

**Difficulty:** Easy

**Language:** Java

**Approach:** Prefix Sum + Array Traversal

**Time Complexity:** O(n)

**Space Complexity:** O(n)

## Problem Statement

Given a 0-indexed integer array `nums`, return an array `answer` such that `answer[i]` is the absolute difference between the sum of the elements to the left of index `i` and the sum of the elements to the right of index `i`.
