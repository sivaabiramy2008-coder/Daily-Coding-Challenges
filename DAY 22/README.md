## Problem 1

**Problem Name:** Maximum Subarray

**Platform:** LeetCode

**Difficulty:** Medium

**Language:** Java

**Approach:** Kadane's Algorithm (Dynamic Programming)

**Time Complexity:** O(n)

**Space Complexity:** O(1)

## Problem Statement

Given an integer array `nums`, find the contiguous subarray with the largest sum and return its sum.

## Problem 2

**Problem Name:** Best Time to Buy and Sell Stock

**Platform:** LeetCode

**Difficulty:** Easy

**Language:** Java

**Approach:** Greedy + One Pass

**Time Complexity:** O(n)

**Space Complexity:** O(1)

## Problem Statement

You are given an array `prices` where `prices[i]` is the price of a stock on the `i`th day. Choose a single day to buy one stock and a different future day to sell it. Return the maximum profit you can achieve. If no profit is possible, return `0`.

- BestTimeToBuyAndSellStock.java
