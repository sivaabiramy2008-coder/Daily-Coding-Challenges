## Problem 1

**Problem Name:** Summary Ranges

**Platform:** LeetCode

**Difficulty:** Easy

**Language:** Java

**Approach:** Array Traversal

**Time Complexity:** O(n)

**Space Complexity:** O(1) (excluding the output list)

## Problem Statement

Given a sorted unique integer array `nums`, return the smallest sorted list of ranges that cover all the numbers in the array exactly. Each range should be represented as `"a->b"` if it contains more than one number, or `"a"` if it contains only one number.

## Problem 2

**Problem Name:** N-th Tribonacci Number

**Platform:** LeetCode

**Difficulty:** Easy

**Language:** Java

**Approach:** Dynamic Programming (Iterative)

**Time Complexity:** O(n)

**Space Complexity:** O(1)

## Problem Statement

The Tribonacci sequence Tₙ is defined as:

- T₀ = 0
- T₁ = 1
- T₂ = 1

For n ≥ 3,

**Tₙ = Tₙ₋₁ + Tₙ₋₂ + Tₙ₋₃**

Given an integer `n`, return the value of the n-th Tribonacci number.
