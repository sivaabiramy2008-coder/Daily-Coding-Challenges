# Day 14 - LeetCode Solutions

## Problem 1

**Problem Name:** House Robber

**Platform:** LeetCode

**Difficulty:** Medium

**Language:** Java

**Approach:** Dynamic Programming (Tabulation)

**Time Complexity:** O(n)

**Space Complexity:** O(n)

## Problem Statement

Given an integer array `nums` representing the amount of money in each house, return the maximum amount of money you can rob without robbing two adjacent houses.
