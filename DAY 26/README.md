# Day 26 - LeetCode Solutions

## Problem 1

**Problem Name:** Subtract the Product and Sum of Digits of an Integer

**Platform:** LeetCode

**Difficulty:** Easy

**Language:** Java

**Approach:** Mathematics (Digit Extraction)

**Time Complexity:** O(d), where d is the number of digits

**Space Complexity:** O(1)

## Problem Statement

Given an integer `n`, calculate the product of its digits and the sum of its digits. Return the result of subtracting the sum from the product.
