# Day 19 - LeetCode Solutions

## Problem 1

**Problem Name:** Complement of Base 10 Integer

**Platform:** LeetCode

**Difficulty:** Easy

**Language:** Java

**Approach:** Bit Manipulation + Bit Mask + XOR

**Time Complexity:** O(log n)

**Space Complexity:** O(1)

## Problem Statement

Given a non-negative integer `n`, return its complement by flipping every bit in its binary representation.
