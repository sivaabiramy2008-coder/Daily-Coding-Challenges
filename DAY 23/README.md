## Problem 1

**Problem Name:** Word Pattern

**Platform:** LeetCode

**Difficulty:** Easy

**Language:** Java

**Approach:** HashMap (Two-Way Mapping)

**Time Complexity:** O(n)

**Space Complexity:** O(n)

## Problem Statement

Given a `pattern` and a string `s`, determine if `s` follows the same pattern. Each character in the pattern must map to exactly one word, and each word must map to exactly one character.
