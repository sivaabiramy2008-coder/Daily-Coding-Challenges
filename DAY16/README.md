# Day 16 - LeetCode Solutions

## Problem 1

**Problem Name:** Minimum Increment to Make Array Unique

**Platform:** LeetCode

**Difficulty:** Medium

**Language:** Java

**Approach:** Sorting + Greedy

**Time Complexity:** O(n log n)

**Space Complexity:** O(1)

## Problem Statement

Given an integer array `nums`, return the minimum number of increments needed to make every element in the array unique. In one move, you can increment any element by `1`.
