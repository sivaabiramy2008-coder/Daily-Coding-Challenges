## Problem 1

**Problem Name:** Nim Game

**Platform:** LeetCode

**Difficulty:** Easy

**Language:** Java

**Approach:** Math / Game Theory

**Time Complexity:** O(1)

**Space Complexity:** O(1)

## Problem Statement

You are playing the Nim Game with a pile of stones. You and your opponent take turns removing 1, 2, or 3 stones. The player who removes the last stone wins.

Given `n` stones, determine whether you can win the game if you make the first move.

## Key Idea

If `n` is a multiple of 4, the first player will lose with optimal play. Otherwise, the first player can win.

## Problem 2

**Problem Name:** Power of Four

**Platform:** LeetCode

**Difficulty:** Easy

**Language:** Java

**Approach:** Bit Manipulation / Mathematics

**Time Complexity:** O(1)

**Space Complexity:** O(1)

## Problem Statement

Given an integer `n`, return `true` if it is a power of four. Otherwise, return `false`.

A number is a power of four if it can be written as `4^x` where `x` is an integer.

## Key Idea

A positive power of four must be a power of two, and its single set bit must appear at an even position.
